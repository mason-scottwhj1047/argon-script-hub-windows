## Overview

Argon PC is a Windows-based Roblox utility for users who need a dedicated Lua script executor in a straightforward desktop application. The software targets Windows 10 and Windows 11, with an emphasis on rapid script loading, one-click injection, and convenient access to frequently used scripts through its built-in hub.

Rather than presenting a large, resource-heavy suite, Argon PC focuses on a compact workflow. Its feature set includes batch execution, locally saved queues, automatic updates, and an integrated debugger, providing the main tools expected from a Roblox script hub while keeping the interface lightweight.
